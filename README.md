# 天命工程 MVP

AI 原生文明跃迁与决策模拟游戏的最小可玩切片。

当前版本只验证一个核心假设：玩家面对“矿井排水危机”时，能否在三种互相冲突的方案之间作出有意义的取舍，并从确定性规则审计中理解结果。

## 本地验证

```bash
npm test
npm run build
npm start
```

- 无运行时依赖；
- `npm test` 验证规则可复现、机会成本和失败关闭；
- `npm run build` 生成 `dist/` 并校验关键内容契约；
- 当前不接入大模型，大模型未来只负责群臣表达与方案生成，不拥有世界状态修改权。

## 当前范围

- 1 个危机场景：北岭煤矿涌水；
- 3 位立场不同的顾问；
- 1 次可执行工程令；
- 4 项国家状态；
- 可解释、可复现的规则结算；
- 不包含账号、数据库、联网模型和多人模式。
